Endpoint Toolbelt 1.0.0 is the first public release: a Windows app that lets employees and IT
support find out why a work app won't install, why Teams keeps asking to sign in or why Windows
Update keeps failing, and fix the common causes without administrator rights.

## Highlights

- **Device health in plain words.** Ten checks and one verdict on Home: the link to Intune, the
  work app installer, the work account, Windows Hello, the network to work services, work
  settings, restart, disk space, the clock and Defender.
- **Problem paths.** An app that won't install, sign-in prompts, no connection, an Office app
  that closes, OneDrive, "not compliant", Windows Update and a window off the screen. Each path
  checks first and changes nothing until the user chooses a step.
- **Every work app explained.** What the device recorded, how far the last attempt got, the
  installer's exit code in plain words and one next step, with a search over all apps.
- **Repairs without admin rights.** Retry work apps and settings, clear downloaded app content,
  a full IME reset, Windows Update check and repair, BitLocker recovery key backup, clock sync,
  Defender definitions, disk cleanup and a new IP address, run by a service that enforces
  confirmations, cooldowns and rate limits.
- **A clean handover to IT.** "Copy details for IT" gives a ticket text with the evidence and no
  device or user names; a support package (`Toolbelt_yyyyMMdd.zip`) collects the logs, the app
  state and the device report.
- **Ready for shared hosts.** Azure Virtual Desktop multi-session is supported: actions that
  affect every session ask first, and administrators can block them.

## Download and verify

`EndpointToolbelt-1.0.0-x64.msi` and its `.sha256` are attached below. The MSI and the
executables and assemblies in it are signed by SoulBit, with a timestamp. The signing certificate
names SoulBit (`O=SoulBit`) and is renewed daily, so compare the subject, not the thumbprint.

```powershell
(Get-FileHash .\EndpointToolbelt-1.0.0-x64.msi -Algorithm SHA256).Hash   # compare with the .sha256
Get-AuthenticodeSignature .\EndpointToolbelt-1.0.0-x64.msi | Format-List Status, SignerCertificate
```

## Install

Windows 10 22H2 or Windows 11, x64, enrolled in Microsoft Intune, .NET Framework 4.8 (in-box).
Deploy it as a Windows app (Win32) in Intune, installed as System, with an MSI detection rule:

```cmd
msiexec /i EndpointToolbelt-1.0.0-x64.msi /qn SUPPORTURL="https://support.soulbit.example"
```

Start with the [admin guide](https://github.com/soulbit-nl/endpoint-toolbelt/blob/v1.0.0/docs/admin-guide.md).
For employees there is a [user guide](https://github.com/soulbit-nl/endpoint-toolbelt/blob/v1.0.0/docs/user-guide.md),
for the service desk an [IT support guide](https://github.com/soulbit-nl/endpoint-toolbelt/blob/v1.0.0/docs/it-support-guide.md).

## Known limitations

- English only, x64 only, no ADMX template (configuration through the MSI or the policy key).
- No central view: IT sees what the user hands over.
- Works on any Intune-managed Windows 10 or 11 device, also a virtual desktop. On a virtual machine
  that does not run on Microsoft Hyper-V, the Windows Hello and clock checks can show a warning that
  does not apply to a virtual desktop.
- Tested on three real devices in two tenants, one of them an Azure Virtual Desktop host, and in
  Windows Sandbox. Not yet confirmed: hybrid-joined devices, non-English Windows, a proxy-only
  network and every route of Repair Windows Update.
- The attack surface reduction rule for prevalence and age can block a new release on its first
  days; [asr.md](https://github.com/soulbit-nl/endpoint-toolbelt/blob/v1.0.0/docs/asr.md) shows how
  to allow it.
